## 2. Données microbiologiques

### 2.1 Création des variables une par une

```{webr}
# Création des variables une par une
echantillon <- 1:10
site        <- c("A","A","A","A","A","B","B","B","B","B")
coliformes  <- c(2, 5, 3, 8, 4, 12, 15, 10, 18, 14)    # UFC/100 mL
e_coli      <- c(0, 0, 1, 0, 0, 2, 3, 1, 4, 2)         # UFC/100 mL
turbidite   <- c(0.5, 0.7, 0.6, 0.9, 0.8, 2.1, 2.5, 1.9, 2.8, 2.3)  # NTU

# afficher les variables créées
echantillon
site
coliformes
```

::: {.callout-note}
**UFC** = Unité Formant Colonie. **NTU** = Nephelometric Turbidity Unit (unité de turbidité). Ces unités sont standard en microbiologie de l'eau.
:::

### 2.2 Vérification de la nature des variables

```{webr}
class(echantillon)   # "integer"
class(site)          # "character"  -> à convertir en facteur
class(coliformes)    # "numeric"
class(e_coli)        # "numeric"
class(turbidite)     # "numeric"

str(site)
```

### 2.3 Conversion des variables `character` en facteur

```{webr}
site <- as.factor(site)
class(site)     # "factor"
levels(site)    # "A" "B"
table(site)
```

::: {.callout-tip}
Une variable catégorielle en `character` est traitée comme du texte par R. La convertir en `factor` permet les regroupements (`tapply`, `boxplot ~ site`) et des tableaux de fréquences corrects.
:::

### 2.4 Création du data.frame (df)

```{webr}
# création du data frame (df)
df <- data.frame(
  echantillon = echantillon,
  site        = site,
  coliformes  = coliformes,
  e_coli      = e_coli,
  turbidite   = turbidite
)

str(df)
summary(df)
```

## 3. Statistiques descriptives

### 3.1 Statistiques globales

```{webr}
# tendance centrale et dispersion
mean(df$coliformes)
median(df$coliformes)
sd(df$coliformes)
min(df$coliformes)
max(df$coliformes)
range(df$coliformes)
quantile(df$coliformes)

mean(df$turbidite)
sd(df$turbidite)
```

### 3.2 Statistiques par site

```{webr}
# statistiques par site
tapply(df$coliformes, df$site, mean)
tapply(df$coliformes, df$site, sd)
tapply(df$turbidite, df$site, median)
```

### 3.3 Tableaux de fréquences

```{webr}
table(df$site)
prop.table(table(df$site)) * 100
table(df$e_coli)
```

::: {.callout-note}
`prop.table()` renvoie des proportions (0–1). Multiplier par 100 donne des pourcentages.
:::

## 5. Créer et enregistrer un graphique

### 5.1 Visualisation interactive (navigateur)

```{webr}
# Boîte à moustaches des coliformes par site
boxplot(coliformes ~ site, data = df,
        main = "Coliformes totaux par site",
        ylab = "UFC/100 mL", col = "lightblue")

# Histogramme de la turbidité
hist(df$turbidite, breaks = 5, col = "lightgreen",
     main = "Distribution de la turbidité", xlab = "NTU")
```

### 5.2 Enregistrement du graphique en PNG (R local)

```{r}
#| eval: false
# Ouvrir le fichier PNG
png(filename = "box_plot.png", width = 800, height = 600)

# Dessiner le graphique
boxplot(coliformes ~ site, data = df,
        main = "Coliformes totaux par site",
        ylab = "UFC/100 mL", col = "lightblue")

# Fermer et sauvegarder
dev.off()
```

::: {.callout-warning}
Ne jamais oublier `dev.off()` : tant que le périphérique graphique reste ouvert, les graphiques suivants ne s'affichent plus à l'écran. En cas d'erreur, taper `dev.off()` dans la console pour le fermer.
